# Screenshot provenance

These are unedited browser captures of TinyPiRelay's `0.5.17-dev` HTML, CSS,
and JavaScript at 1600 × 900, captured on 2026-09-13. Dashboard, Audio and
Storage keep the **SIMULATED LOCAL PREVIEW · NO PI** indicator visible; the
Recovery dialog uses the application's normal blurred backdrop. These images
illustrate the interface, not hardware performance or microphone evidence.

- `dashboard.png`: the existing local preview supplies synthetic telemetry over the real HTTP/SSE service. The capture waits for the full 30-second spectrogram history; no chart or DOM is substituted.
- `audio.png`: the actual capture and analysis controls with the preview's sample configuration.
- `storage.png`: six sample recording rows supplied through intercepted storage API responses, including finalized, needs-checking, and checked states. Playback uses a muted, paused, disposable eight-second FLAC tone generated by ffmpeg. Recording is stopped through the real preview controls before capturing Storage.
- `recovery.png`: the real recovery confirmation opened for a sample row while recording is stopped and then cancelled. Recovery is never submitted.

The preview uses sample names, `preview.invalid`, and the documentation address `192.0.2.94`. Its ephemeral password is consumed in memory and is never printed by the capture script or included in an image. The browser has a fresh context; no existing browser profile, account, Pi, microphone, recording, or stream is used.

## Reproduce

With Node.js, Python 3, ffmpeg, and Playwright with Chromium already installed, run from the repository root:

```sh
node spikes/docs_screenshots.cjs
```

The script follows the existing browser-check pattern. Set `PLAYWRIGHT_MODULE` to an existing Playwright module path, `TEST_PYTHON` to a Python executable, or `BROWSER_EXECUTABLE` to an installed browser executable when needed. `TEST_BROWSER` defaults to `chromium`; `TEST_PORT` defaults to `18087`.

It starts only a hidden loopback preview and headless browser, permits browser requests only to that preview, and blocks mutations apart from the disposable login and one simulated `recording.stop` action. It checks for page errors and document overflow at each capture. Browser and preview processes are stopped and the temporary tone is removed in `finally`. Output overwrites only the four PNGs beside this file. No publishing is performed.
